# BookLedger Basic

Die **PWA-Fassung** von [BookLedgerPro](https://github.com/lausiklauskn-png/BookLedgerPro): offline-first, verschlüsselte
Buchhaltung (Deutschland zuerst), KI nur mit eigenem Schlüssel und nur nach Bestätigung, ins Sage-Mycel eingebunden.
Build-frei, keine CDNs, GitHub Pages: `https://lausiklauskn-png.github.io/BookLedger-Basic/`.

Der Inhalt kommt aus dem Pro-Repo (`node tools/pro-nachziehen.mjs --pro ../BookLedgerPro`, Pin in `HERKUNFT-PRO.json`);
hier wird nichts von Hand geändert. Was Basic von Pro unterscheidet, steht in `CLAUDE.md` und `tools/basic-regeln.mjs`.
BookLedgerPro selbst wird die native App (Android + Windows).
